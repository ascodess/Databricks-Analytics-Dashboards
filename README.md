# Dashboard 1: Transaction Analytics Dashboard

### Project Objective

Analyze transaction data to identify sales trends, top-performing products, payment method preferences, and purchasing behavior.

### Key Features

* Global quantity filter
* Top products by total revenue
* Payment method distribution
* Sales quantity trend over time
* Interactive dashboard filtering

### Business Insights

* Identified highest revenue-generating products.
* Compared customer payment preferences.
* Analyzed transaction volume trends.
* Enabled dynamic exploration through dashboard filters.

# Dashboard 2: United States Emissions Dashboard

### Project Objective

Analyze environmental emission data across the United States to identify emission hotspots, state-level contributions, and population-emission relationships.

### Key Features

* Geographic emissions map
* Emissions vs population analysis
* Top emitting counties
* State-wise emission contribution
* Interactive filtering and exploration

### Business Insights

* Visualized geographical emission distribution.
* Examined relationships between population and emissions per person.
* Identified highest emitting counties.
* Analyzed state contribution to total emissions.

# SQL Workflow

The dashboards were created using Databricks SQL and followed the workflow below:

1. Imported raw datasets into Databricks.
2. Cleaned and transformed data using SQL queries.
3. Created analytical views and aggregations.
4. Built visualizations from query outputs.
5. Combined visualizations into interactive dashboards.
6. Added filters and dashboard-level interactivity.
